# Runtime dependencies for btc-range-model
#
# ┌─────────────────────────────────────────────────────────────────────────┐
# │ DEPLOY THIS APP ON PYTHON 3.12.                                          │
# │ Set it in Streamlit Community Cloud → Manage app → Settings (or the      │
# │ "Advanced settings" dialog when you (re)deploy). runtime.txt is IGNORED  │
# │ by Streamlit Cloud (streamlit issue #15326), and the platform default    │
# │ (Python 3.14) segfaults this app's native ML stack at runtime.           │
# └─────────────────────────────────────────────────────────────────────────┘
#
# Why 3.12: the trained model (models/inference_assets_ct.joblib) is pickled
# with scikit-learn 1.8.0. On Python 3.14 the only installable builds are the
# bleeding-edge numpy 2.5 / pandas 3.0 / scikit-learn 1.9 wheels, whose native
# ABI combination SEGFAULTS after the UI renders (confirmed on the deployed app;
# not reproducible on 3.12/3.13 with the pinned set below). scikit-learn 1.8.0
# also has no cp314 wheel, so on 3.14 it would build from source and hang the
# deploy ("in the oven"). Python 3.12 has wheels for the exact tested set and
# runs cleanly.
#
# Validated together on Python 3.12 (uv + pip): model loads with no version
# warning, full model-predict pipeline runs with no segfault, streamlit starts.
# numpy 2.1.3 · pandas 2.2.3 · scipy 1.14.1 · scikit-learn 1.8.0 · pyarrow 24.
#
# pyarrow: MUST stay < 25. pyarrow 25.0.0 has a memory-corruption bug in its
# pandas->Arrow conversion (pyarrow.pandas_compat.convert_column) that SEGFAULTS
# Streamlit's st.dataframe serializer after several reruns — reproduced reliably
# on the MSTR Backtesting tab, whose trade-log tables (esp. the higher-trade
# Pure Regime / Bull Regime gates) tip repeated renders into a native crash
# (exit 139). 24.0.0 and below convert the identical tables cleanly across
# hundreds of renders. The prior cap (<26) let the broken 25.0.0 resolve in.

# Core scientific stack — upper-bounded to the tested, no-segfault majors
numpy>=1.26,<2.3
pandas>=2.1,<2.3
scipy>=1.11,<1.15
scikit-learn==1.8.0       # MUST match the pickled model
joblib>=1.3,<1.6
pyarrow>=14,<25           # Streamlit's dataframe serializer — MUST stay below 25 (see note)

# Data feeds
yfinance>=0.2.40
requests>=2.31

# Web app  (no upper bound on streamlit — the platform manages its version)
streamlit>=1.30
plotly>=5.18
# Live auto-refresh of the Overall Trading price column (optional — the app
# degrades gracefully to click/reload refresh if this is unavailable).
streamlit-autorefresh>=1.0.1

# AI Assistant page (app/assistant_app.py) — the Anthropic SDK.
# Only the long-stable surface is used (messages.stream, models.list), so both
# the 0.x and 1.x majors work; the page degrades to a "no API key" notice if the
# key is absent and every OTHER page runs fine even if this import fails.
anthropic>=0.69,<2

# Notebook generation
nbformat>=5.9
